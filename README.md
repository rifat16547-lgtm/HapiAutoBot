# Hapi Auto Bot (Android)

Build the APK without Android Studio:
1. Create a new GitHub repo, upload everything in this folder (keep the `.github` folder).
2. Repo > Actions > "Build APK" > wait for green tick (2-5 min).
3. Open the finished run > Artifacts > HapiAutoBot-apk > download, unzip, install `app-debug.apk`.

Use: open the app > enable Accessibility service > tap START on the floating panel.
